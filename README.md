# Student Management System

A Python-based Student Management System that uses SQLite to store and manage student records.

## Features

- Add new students
- View all student records
- Search students by name
- Update student details
- Delete student records with confirmation
- Sort students by marks
- View student statistics
- Filter students by course
- View pass/fail results
- Import student records from CSV files
- Export student records to CSV files
- Validate user inputs

## Technologies Used

- Python
- SQLite
- CSV

## Requirements

- Python 3 installed
- Visual Studio Code (recommended)

## How to Run

1. Download or clone this project.
2. Open the project folder in your terminal.
3. Run the following command:

   `python3 main.py`

4. Follow the menu instructions to manage student records.

## Database

The application uses SQLite to store student information in `student_management.db`.

## Learning Outcomes

This project demonstrates Python functions, loops, conditional statements, exception handling, SQL queries, database operations, and CSV file handling.
